# Datenbank-Neustart

Dieses Repository wird von Grund auf neu aufgebaut.

## Architektur

- Spieler
- Vereine
- Landesverbände
- Turniere
- Ergebnisse
- Rundenergebnisse
- DRL-Einträge
- DMV-Einträge

Alle Beziehungen werden vor Veröffentlichung geprüft. Unklare Identitäten bleiben unverknüpft und werden separat protokolliert.

## Datenquellen

Die vorhandenen Archive werden als Rohquellen behandelt. Bereits erzeugte Beziehungen aus älteren Versionen werden nicht als Wahrheit übernommen.
